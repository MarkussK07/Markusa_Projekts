# Ielogošanās

Ievadi:
E-pasts
Parole
Spied “Ieiet”

# Olimpiādes pieteikšana
Atver sadaļu “Pieejamās olimpiādes”
Spied pogu “Pieteikties”
Ievadi:
Tava tālruņa numurs
Vecāka/aizbildņa vārds un uzvārds
Vecāka/aizbildņa tālruņa numurs
Motivācijas vēstule (nav obligāta)
Spied “Pieteikties”
Pieteikums tiks saglabāts datubāzē.

# Manu pieteikumu apskate
Spied “Mani pieteikumi”
Redzēsi visas olimpiādes, kurām esi pieteicies
